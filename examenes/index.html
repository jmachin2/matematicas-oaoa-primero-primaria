Generador de prueba competencial

Selecciona las fichas trabajadas. La página analiza las estrategias OAOA, los aprendizajes curriculares del primer ciclo y la carga de evaluación antes de generar la prueba y su rúbrica.

1. Elige las fichas que quieres evaluar

No se copian literalmente las fichas. Se evalúan las destrezas y relaciones matemáticas que se han trabajado con ellas.

Importante: el Decreto 211/2022 prescribe competencias, criterios y saberes para el primer ciclo (1.º-2.º). Esta herramienta concreta la evaluación para 1.º a partir de las fichas realmente trabajadas; no presenta esa secuenciación como una distribución normativa cerrada por curso.

2. Análisis de lo que se evaluará

Selecciona al menos una ficha para ver el análisis.
📄 Límite fijo para el alumnado: la prueba nunca ocupará más de 2 folios. Si seleccionas muchas fichas, el generador integrará varias destrezas en tareas competenciales representativas y, cuando sea necesario, distribuirá la evaluación en dos sesiones de un folio cada una.

3. Genera los instrumentos

La prueba combina representación, estrategia, cálculo, resolución y explicación. La rúbrica valora cómo piensa el alumnado, no solo si acierta.
