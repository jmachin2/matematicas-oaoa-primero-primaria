# Matemáticas OAOA · CEIP Camino Largo

Web interactiva de Matemáticas para 1.º de Primaria basada en el trabajo con regletas,
composición y descomposición, cálculo, resolución de problemas y actividades OAOA.

## Publicar con GitHub Pages

1. Sube **todo el contenido de este paquete** a la raíz de tu repositorio.
2. En GitHub entra en **Settings → Pages**.
3. En **Build and deployment**, selecciona:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Guarda.
5. GitHub mostrará la URL pública cuando termine el despliegue.

El archivo `index.html` de la raíz abre automáticamente la sección **Fichas**.

## Estructura principal

- `fichas/`
- `recursos/`
- `vocabulario/`
- `juegos/`
- `examenes/`
- páginas interactivas hasta `pagina-21/`
- `assets/`

## Notas

- La web es estática: no necesita backend.
- Los recursos principales funcionan desde GitHub Pages.
- Los vídeos opcionales de YouTube de las páginas 17 y 19 necesitan conexión a Internet.
- La generación y descarga de PDFs se realiza en el navegador.
